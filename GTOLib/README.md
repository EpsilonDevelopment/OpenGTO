# GTOLib 26.8.3-techtree — Restored Source Project

> Location: this tree now lives at `GTOCore/GTOLib`, the path of the official `GTOLib` git
> submodule (`https://github.com/GregTech-Odyssey/GTOCore-GTOlib.git`, private). GTOCore's
> `gradle/scripts/gtolib-pipeline.gradle` detects it through
> `GTOLib/src/main/java/com/gtolib` and merges it into `sourceSets.main`.
> GTOCore's default `./gradlew clean build` succeeds: the pipeline matches the restored tree
> against the committed sealed pair and reuses it (`jarUpToDate=true`). Forcing a build from this

> stops only at the private sealing step; see `docs/KOTLIN-FIDELITY-GAP.md`.

Reverse-engineered source tree of the official **GTOLib** build shipped with GregTech Odyssey
`26.8.3-techtree`, restored from the sealed artifact `libs/gtolib-protected.jar`
(GTO-Seal encrypted + ProGuard obfuscated, no source repository access).

Status: **compiles and builds cleanly.**

```text

BUILD SUCCESSFUL
```

The official GTOLib is **not a standalone repository project**. Its build script
(`gtolib-pipeline.gradle` in the GTOCore repository) merges `GTOLib/src/main/java` into GTOCore's
`sourceSets.main`, compiles it together with GTOCore, filters `com/gtolib/**` out of the result and
only then runs ProGuard + GTO-Seal. This directory reconstructs the `com/gtolib` half of that
pipeline as a self-contained, buildable Gradle project.

## Layout

```text
build.gradle / settings.gradle / dependencies.gradle / gradle.properties
gradle/                      Gradle wrapper + moddevgradle/repositories scripts
libs/                        local compile dependencies (see BUILD-AND-VERIFY.md)
src/main/java/com/gtolib/**    620 restored Java sources
src/main/kotlin/com/gtolib/**  13 restored Kotlin sources (37 Kotlin-origin classes)
src/main/resources/            gtolib.mixins.json, META-INF/accesstransformer.cfg
docs/                        restoration report, build/verification record, read index
```

The refmap (`gtolib.refmap.json`) is **not** kept in `src/main/resources`: it is generated by the
Mixin annotation processor during the build, exactly as in the official pipeline.
